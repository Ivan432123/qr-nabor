# Меню заведений

Готовые комплекты для клиентов: одна папка = одно заведение.

В папке заведения:
- `index.html`, `404.html` — меню (копируется целиком туда, где оно будет жить)
- `qr/` — печатные карточки столов (`stoly-<имя>.pdf`, `cardN.png`) и чистые QR (`qrN.svg`)

Боевая копия меню для выкладки на `<имя>.qrstol.ru` лежит в `cafes/<имя>/`.
Эта папка на сайт не выкладывается.
